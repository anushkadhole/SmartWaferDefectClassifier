# 🚀 Smart Wafer Defect Classifier

A deep learning app that detects semiconductor wafer defects using PyTorch, TensorFlow, and scikit-learn. Features live prediction via Streamlit dashboard.

## Features
- CNN-based classification model
- NumPy & scikit-learn for EDA + preprocessing
- Live dashboard using Streamlit
- Deployable on Render or Hugging Face

## Tech Stack
- PyTorch
- TensorFlow
- NumPy
- scikit-learn
- Streamlit
